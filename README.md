# Gintong Araw CDA — Member Management System

Member records, ID cards with QR codes, and meeting attendance for the Gintong Araw Community Development Association, Inc.

Specs and roadmap: [docs/README.md](docs/README.md)

## Requirements

- Node.js 20.9+ (developed on 22)
- pnpm 11

## Getting started

```bash
pnpm install          # also runs `prisma generate`
cp .env.example .env.local
pnpm dev              # http://localhost:3000
```

Credentials are added phase by phase (see [docs/02-tech-stack.md](docs/02-tech-stack.md#environment-variables)). Phase 0 runs without any of them.

## Scripts

| Command                     | What it does                                                                 |
| --------------------------- | ---------------------------------------------------------------------------- |
| `pnpm dev`                  | Dev server (Turbopack)                                                       |
| `pnpm build` / `pnpm start` | Production build / serve                                                     |
| `pnpm lint`                 | ESLint                                                                       |
| `pnpm typecheck`            | Generate route types + `tsc`                                                 |
| `pnpm format`               | Prettier (with Tailwind class sorting)                                       |
| `pnpm db:migrate`           | Create/apply a migration (needs `DIRECT_URL`)                                |
| `pnpm db:seed`              | Sync permissions, default groups and the first Super Admin (safe to re-run)  |
| `pnpm db:seed:psgc`         | Load PH regions/provinces/cities/barangays (PSGC) — run once per database    |
| `pnpm db:studio`            | Prisma Studio                                                                |
| `pnpm icons`                | Regenerate favicon/app icons from `logo.png` (pass a path for a hi-res logo) |

## Project layout (non-code)

| Path                                      | What it is                                                                                   |
| ----------------------------------------- | -------------------------------------------------------------------------------------------- |
| `design/brand/logo.png`                   | Source logo for `pnpm icons`                                                                 |
| `design/id-template/ID - Template.psd`    | ID card source design (positions in `src/features/id-card/layout.ts` come from it)           |
| `src/features/id-card/assets/`            | Card templates + font used by the renderer (kept out of `public/` — the back has signatures) |
| `public/mediapipe/models/`                | Background-removal model (committed)                                                         |
| `public/mediapipe/wasm/`, `public/zxing/` | Browser WASM engines — generated by `pnpm install`, not committed                            |
| `scripts/copy-vendor-wasm.mjs`            | Runs on install; copies the WASM engines above                                               |
| `scripts/generate-icons.mjs`              | `pnpm icons` — favicon / PWA icons from the logo                                             |

## Deploying to Vercel

1. Push to GitHub (keep the repository **private** — it contains the ID templates with officers' signatures).
2. In Vercel: **Add New → Project →** import the repo. Framework: Next.js. Install/build commands: defaults.
3. **Environment variables** (Production + Preview):

   | Name                                                                     | Value                                              |
   | ------------------------------------------------------------------------ | -------------------------------------------------- |
   | `DATABASE_URL`                                                           | Neon pooled connection string                      |
   | `DIRECT_URL`                                                             | Neon direct connection string                      |
   | `BETTER_AUTH_SECRET`                                                     | same as `.env.local`                               |
   | `BETTER_AUTH_URL`                                                        | `https://gintongaraw.coderyan.dev`                 |
   | `APP_URL`                                                                | `https://gintongaraw.coderyan.dev`                 |
   | `R2_ACCOUNT_ID`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`, `R2_BUCKET` | same as `.env.local`                               |
   | `ENABLE_EXPERIMENTAL_COREPACK`                                           | `1` (so Vercel uses pnpm 11 from `packageManager`) |

4. **Domain:** Project → Settings → Domains → add `gintongaraw.coderyan.dev`, then at your DNS provider add the record Vercel shows (usually `CNAME gintongaraw → cname.vercel-dns.com`).
5. **Database changes:** migrations are not run during the build. After adding a migration, apply it once with `pnpm exec prisma migrate deploy` (uses `DIRECT_URL`).
